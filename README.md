## Design and interactions

Responsive layouts, light and dark themes, repeatable scroll reveals, subtle background motion, project image hover effects, and an accessible screenshot dialog. Animations respect the visitor's reduced-motion preference.

## Built with

HTML5, CSS3, and vanilla JavaScript. No build step or framework is required. Hosted on Vercel.

## Run locally

```sh
git clone https://github.com/nourbatniji/Portfolio.git
cd Portfolio
python3 -m http.server 8080 --bind 127.0.0.1
```

Open [localhost:8080](http://localhost:8080).

## Project structure

```text
index.html   Page content and sections
style.css    Responsive styles, themes, and animations
main.js      Theme toggle, scroll reveals, navigation, and screenshot gallery
assets/      Project images, certificates, and CV
```

## Update the portfolio

Edit `index.html` to update content and links, `style.css` for presentation, and `main.js` for interactions. Place new images or documents in `assets/` and update their references in the HTML. Keep project status and personal information accurate before publishing.

## Deployment

The production site is hosted in the Vercel project `portfolio`. To deploy manually with the Vercel CLI:

```sh
vercel link --project portfolio
vercel --prod
```
